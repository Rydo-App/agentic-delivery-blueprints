## How to join the list

A sponsorship at any level adds the sponsor's name to the table above. The top level
adds a logo to the readme as well.

The levels, and what each one funds:

| Level | Funds |
| --- | --- |
| Bronze | Maintainer time for the review queue. |
| Silver | Maintainer time and the hosted runners the continuous integration needs. |
| Gold | Maintainer time, the hosted infrastructure, and the response to a reported vulnerability. |
| Platinum | Everything above, and the tooling and licences the project depends on. |

A sponsorship buys capacity for the project as a whole. It does not buy a place in the
order of the backlog, a private support channel, a response time, or a feature.
